A 2D mechanics sandbox for AP Physics C: Mechanics. Draw textbook-style diagrams, press Play, and watch them move with real physics in SI units. It includes free-body diagrams, live readouts, graphs with CSV export, 13 classic AP presets, and 40 built-in accuracy tests.

## Which file do I download?

| File | What it is |
|---|---|
| **MechanicsSandbox-…-portable.exe** | Just double-click it; nothing gets installed. Good for school computers or a USB stick. It takes a few seconds to open each time. |
| **MechanicsSandbox-…-setup.exe** | A normal installer that adds a Start-menu and desktop shortcut. It opens faster after that. |
| **mechanics-sandbox.html** | The same app as a single web page, for Mac, Chromebook or Linux. Open it in Chrome or Edge (it needs internet the first time, to load two libraries). |

The Windows app works completely offline.

## "Windows protected your PC"

The app isn't code-signed (a signing certificate costs a few hundred dollars a year), so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**. The source code is in this repository.

## Saving work

**Save** downloads your scene as a `.json` file, and **Open…** loads it again. The app also autosaves your last scene.
